# Git-тренажёр

Страница для занятия 2: схема «четыре места», 18 уровней с эмулятором терминала и автопроверкой, подключение к GitHub, шпаргалка и домашка, вкладка «Урок» для опроса в прямом эфире.

Страница руководителя — `teacher.html` (вход через Supabase Auth, как в панели отбора). Данные учеников — только в Supabase, доступ у email руководителя; SQL — `Урок_2_git/supabase_git_teacher.sql` и `supabase_git_live.sql`.

Открыть: https://www.irtuganov.pro/git-2107/ (или файл `index.html` локально — работает без интернета).

## Файлы

- `index.html` — страница и интерфейс.
- `live.js` — связь с Supabase для учеников (личный ключ, события, текущий вопрос). `quiz.js`, `quiz.css` — вопросы опроса и их вид.
- `teacher.html`, `teacher.js` — страница руководителя.
- `engine.js` — движок: модель репозитория, команды git, уровни и их проверки. Константа `ORG` в начале — аккаунт GitHub с учебным репозиторием.
- `тест.mjs` — прогон всех уровней: `node тест.mjs` (`-v` — с выводом команд).

## Публикация

Репозиторий https://github.com/Vonagu3/git-2107, GitHub Pages из ветки `main`. Адрес на домене irtuganov.pro получается сам: так же, как у otbor-2107, домен задан в Vonagu3.github.io.

После изменений: `./publish.sh "что поменял"` — обновит версию engine.js (чтобы браузеры не брали старый кэш), закоммитит и отправит. Перед этим — `node тест.mjs`.

## Как добавить уровень

В `engine.js` добавить объект в `LEVELS`: `setup` строит стартовый мир, `goals` — цели с проверками, `hints` — подсказки, `solution` — эталонные команды для `тест.mjs`, `bad` — необязательный неправильный путь, который не должен засчитываться. После правки — `node тест.mjs`.
