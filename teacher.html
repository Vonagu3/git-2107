Ученики

Изменения сохраняются сами. Каждому нужен личный ключ: отправьте ученику ссылку из столбца «Ключ» — тренажёр запомнит его, и уровни, ответы опроса и результаты python проверить.py будут появляться здесь. Обновляется каждые 5 секунд.

Результаты опросов

Каждый проведённый опрос сохраняется. Учитывается последний ответ ученика на вопрос. Вопрос 1 — голосование, в счёт не идёт.

Сообщения для рассылки

Каждому — его сообщение, в личку, не в общий чат: по ссылке тренажёр узнаёт ученика. «Отправлено» — просто пометка для вас.

Подготовить заранее

    Ход занятия

    Нажмите на команду — она скопируется для чата MAX. Скопированные отмечаются зелёным.

    Опрос (если проводите снова)

    1. «Начать опрос» → «Режим показа» → демонстрация окна этой страницы. Ученики — вкладка «Урок».
    2. Каждый вопрос: ждать «ответили N из M» → «Показать ответ» → разбор → «Дальше». В конце «Завершить». Результаты — в блоке «Результаты опросов».

    Как пользоваться тренажёром на занятии

    • Тренажёр задан на дом: по столбцу «Тренажёр» видно, кто сколько прошёл. На занятии — тем, кто закончил задания раньше: уровни 13–18.
    • Командные задания К1–К3 (pull request с review, конфликт в команды/А.md и Б.md, issues с идеями) описаны в ЗАДАНИЯ.md; следить — во вкладках Pull requests и Issues репозитория.
    • С ключом тренажёр отправляет только номера пройденных уровней и ответы опроса — без имени. Без ключа ничего не уходит, тогда отчёт — карточка с кодом (проверка под таблицей).
    • Уровень 15 (конфликт) удобно показать на проекторе перед разбором конфликта на настоящем GitHub.
    • Код можно подобрать, прочитав код страницы, — это мотивация, а не экзамен. Настоящая проверка — python проверить.py и ветки на GitHub.

    Практика в парах (дома, после занятия)

    Каждая пара создаёт свой закрытый репозиторий из шаблона Vonagu3/praktika-shablon и приглашает вас. Задание — в README шаблона: миссии 0–4, 1,5–2 часа в созвоне. Прогресс — в столбце «Практика в парах» таблицы учеников: ученик запускает python проверить.py в репозитории пары, 7 шагов (миссия 0, визитка, оба PR недели, свой конфликт, вопрос, идея, пара закончила). Request changes скрипт не видит — его смотреть на GitHub. Пары ученикам сообщить в чате (на странице учеников имён нет).

    Как помогать

    • Смотрите на столбец «проверить.py» в таблице учеников, а не на экраны: там написано, где ученик застрял.
    • Не работает Git или вход: класс не ждёт. Командные задания можно сделать в браузере, через значок карандаша.
    • Отстаёте: задание 6 и issues переносите на дом. Командный конфликт не урезать.

    Что сознательно не рассказываем

    Rebase, теги, stash, git reset, SSH-ключи. Конфликты на настоящем GitHub ученики сами не устраивают — только в тренажёре и на разборе на экране.
