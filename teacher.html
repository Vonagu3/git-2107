    Как помогать

    • Застрявший присылает в чат скрин терминала с последней командой и ответом git — по нему видно, на каком шаге.
    • Ответы детектива — в личку, чтобы не подсказать остальным.
    • Отстаёте: rebase -i не показывать; в практике rebase с конфликтом сделать вместе на экране.
    • Кто закончил раньше: на GitHub открыть kopilka.py → Blame и пройти назад по строке 20 кнопкой «View blame prior to this change» до самого первого автора.
