    Разбор слабых вопросов опроса (0–10 мин)

    По итогам опроса 29.09 хуже всего решены №8, №11, №13 (по 67%). Демонстрация — вкладка тренажёра «Как устроен Git».

    1. №8, отказ push. Кнопки: изменить → add → commit → push; «коллега отправил»; снова изменить → add → commit → push — отказ. «Git не даёт затереть чужую работу». Затем pull → push.
    2. №11, ветки. Схема веток внизу вкладки: коммиты в ветке «аня» не меняют main, пока её не сольют (последний кружок — слияние).
    3. №13, где история. В своём клоне в терминале: ls -a (Windows: dir /a) — папка .git. «Вся история здесь, интернет нужен только для push и pull».

    Опрос (если проводите снова)

    1. «Начать опрос» → «Режим показа» → демонстрация окна этой страницы. Ученики — вкладка «Урок».
    2. Каждый вопрос: ждать «ответили N из M» → «Показать ответ» → разбор → «Дальше». В конце «Завершить». Результаты — в блоке «Результаты опросов».

    Как пользоваться тренажёром на занятии

    • Тренажёр задан на дом: по столбцу «Тренажёр» видно, кто сколько прошёл. На занятии — тем, кто закончил задания раньше: уровни 13–18.
    • С ключом тренажёр отправляет только номера пройденных уровней и ответы опроса — без имени. Без ключа ничего не уходит, тогда отчёт — карточка с кодом (проверка под таблицей).
    • Уровень 15 (конфликт) удобно показать на проекторе перед разбором конфликта на настоящем GitHub.
    • Код можно подобрать, прочитав код страницы, — это мотивация, а не экзамен. Настоящая проверка — python проверить.py и ветки на GitHub.

    Типовые проблемы

    • «fatal: not a git repository» — не в той папке, cd git-praktika.
    • Терминал не видит git на Windows — не установлен или не перезапущен VS Code после установки.
    • python не найден на Windows — не поставили «Add to PATH»; использовать py.
    • push просит логин/пароль в терминале — не сработал Git Credential Manager. Переустановить Git for Windows с настройками по умолчанию или войти через VS Code (Accounts → Sign in with GitHub).
    • 403 / «Repository not found» при clone или push — ученик не принял приглашение (репозиторий закрытый) или вошёл под другим аккаунтом.
    • «Need to specify how to reconcile divergent branches» — git config --global pull.rebase false.
    • Кириллица в имени ветки работает, но если где-то ломается — латиница.
    • Открылся Vim после git commit без -m: Esc, :wq, Enter. Профилактика: git config --global core.editor "code --wait".

    Что сознательно не рассказываем

    Rebase, теги, stash, git reset, SSH-ключи. Конфликты на настоящем GitHub ученики сами не устраивают — только в тренажёре и на разборе на экране.
