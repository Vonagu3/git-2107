Ветки

Ветка — отдельная линия истории. У каждого своя ветка, в main попадает только проверенное. Слить ветку в main — это git merge или кнопка Merge в pull request на GitHub.

git pull                       # 1. забрать чужое
# ... правим файлы ...
git status                     # 2. посмотреть, что изменилось
git add .                      # 3. отметить всё для коммита
git commit -m "Что сделал"     # 4. сохранить версию
git push                       # 5. отправить на GitHub

Подключаемся к настоящему GitHub

Делается один раз на каждом компьютере. Отмечайте шаги галочками — они запомнятся в этом браузере.

  1. Установить Git, Python и VS Code

    Git: git-scm.com/downloads. На Windows при установке всё оставить по умолчанию. На Mac ввести в терминале git --version и согласиться на установку.

    Проверка в терминале VS Code (меню Terminal → New Terminal):

    git --version
python --version       # на Windows может быть: py --version

    Если Windows пишет «git не является командой» — закройте и откройте VS Code заново.

  2. Аккаунт на GitHub

    Регистрация на github.com/signup. Нужна почта, к которой есть доступ: придёт код. GitHub можно с 13 лет — если меньше, работаете в паре с соседом, а аккаунт заводите дома вместе с родителями.

    Логин выбирайте так, чтобы было понятно, кто вы: ivan-petrov, а не xXx_killer. Логин отправьте в чат группы.

  3. Принять приглашение в учебный репозиторий

    Руководитель пригласит ваш логин в репозиторий git-praktika. Приглашение придёт на почту, или откройте и нажмите «Accept invitation». Репозиторий закрытый: без приглашения его не видно. Без этого push не пройдёт: будет ошибка 403.

  4. Представиться git

    Почта — та же, что на GitHub. Третья строка избавит от ошибки «divergent branches» при pull.

    git config --global user.name "Имя Фамилия"
git config --global user.email "почта@как.на.github"
git config --global pull.rebase false

    Проверить: git config --list. В тренажёре это уровень 1.

Все команды тренажёра

  

    
КомандаЧто делает

    
git statusЧто изменилось. Ничего не ломает — вводите сколько угодно.

    
git add файл
git add .		Отметить файл (или всё) для следующего коммита.

    
git commit -m "..."Сохранить версию с подписью. Подпись — по-русски, глаголом: «Добавил файл с шагами».

    
git log --onelineИстория кратко. git log — с авторами и датами.

    
git show a1b2c3dЧто поменялось в коммите.

    
git diffЧто изменено, но ещё не добавлено. git diff --staged — что уже в индексе.

    
git restore файлОтменить несохранённые правки в файле (вернуть как в последнем коммите).

    
git restore --staged файлУбрать файл из индекса, правки остаются.

    
git rm --cached файлПерестать хранить файл в git, но оставить в папке.

    
git branchСписок веток, * — текущая. git branch -a — вместе с ветками GitHub.

    
git checkout -b имяСоздать ветку и перейти в неё (то же: git switch -c имя).

    
git checkout имяПерейти в ветку (то же: git switch имя).

    
git merge имяСлить ветку в текущую. git merge --abort — отменить слияние с конфликтом.

    
git clone ссылкаСкачать репозиторий с GitHub. Один раз.

    
git remote -vКуда смотрит origin.

    
git push -u origin имяПервый push новой ветки. Дальше — просто git push.

    
git pullЗабрать и слить изменения с GitHub.

    
git fetchТолько узнать, что нового на GitHub, ничего не сливая.

  

  
Конфликт

  
Git остановился и написал CONFLICT. В файле появились метки:


<<<<<<< HEAD
ваша версия строки
=======
версия из другой ветки
>>>>>>> шаги

  
Оставьте правильный вариант (или напишите общий), удалите три строки-метки, сохраните, затем git add файл и git commit -m "Решил конфликт". В VS Code над конфликтом есть кнопки «Accept Current / Incoming / Both».

  
Что не кладём в репозиторий

  
Папку venv, файлы больше 50 МБ, пароли и ключи (.env), картинки, которые скрипт создаёт сам. Для этого есть файл .gitignore — одна строка на шаблон: *.png, venv/.

  
Команды терминала

  
ls (Windows: dir) — список файлов, cd папка — войти, cd .. — выйти, cat файл — показать файл. В тренажёре ещё есть edit файл — открыть в редакторе.
